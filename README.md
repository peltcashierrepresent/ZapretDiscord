> ### ЕСЛИ АНТИВИРУС РЕАГИРУЕТ НА WinDivert
>
> Для работы zapret требуется WinDivert — средство перехвата и фильтрации сетевого трафика.  
> Этот инструмент может применяться разными программами, в том числе вредоносными, но сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и помещается в карантин. В названии обнаружения обычно присутствует `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky используется настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, предпочтительнее добавить исключение для каталога. При недостаточном понимании настроек рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы — инструкция находится [здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите опцию "Транзит запросов". Если её отключить, Secure DNS на компьютере может работать некорректно

2. Откройте [страницу последнего релиза](https://github.com/peltcashierrepresent/zapret-discord-youtube/releases/latest) и скачайте архив в формате zip или rar

3. Откройте свойства загруженного архива и выберите "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно пропустить

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для автоматического запуска выберите в **`service.bat`** пункт `Install Service`, затем укажите подходящую стратегию

## ℹ️Назначение основных файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую именно для вашей системы**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в службы Windows для автозапуска</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из списка служб
  - **`Check Status`** — отображение состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — смена режима обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно запустить заново.**  
  Текущее состояние указывается в скобках: включено или выключено.
  - **`IPSet Filter`** — выбор режима обработки сервисов, перечисленных в `ipset-all.txt`.  
  Этот параметр полезен при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается текущий режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — адрес проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена используемого fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret не запускается или не работает.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном отказе приложения
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues/522)

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить файл вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Найдите появившийся файл `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленный аналогичный фрагмент
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа этого способа не гарантируется. Если он не помог, используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/peltcashierrepresent/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Рабочие стратегии могут меняться со временем.**
> Обнаружение определённой стратегии способно произойти спустя некоторое время, после чего она перестанет работать.
> В проекте собрано много вариантов обхода. Если готовые варианты не подходят, создайте собственную стратегию на основе одной из них и измените её параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок

- Убедитесь, что адрес нужного ресурса присутствует в списке доменов или IP-адресов

- Проверьте остальные варианты, включая **`ALT`**, **`FAKE`** и другие стратегии

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и другие данные
- Перезапустите компьютер
- Откройте `service.bat` -> `Remove Services`
- Затем выполните `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите старый каталог zapret
- Загрузите свежую версию со [страницы релизов](https://github.com/peltcashierrepresent/zapret-discord-youtube) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если в нижней части окна есть пункт разблокировки, включите его, нажмите "Применить", затем "ОК"
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте доступ к нужным ресурсам. Если доступ не появился, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение перестали работать при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкции опубликованы [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide)

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Сначала найдите имя службы в командной строке Windows. Нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите найденную службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Переберите остальные стратегии, особенно если раньше доступ уже работал
- Также см. [#251](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- После очистки проверьте приложение ещё раз
- Откройте Discord через браузер: https://discord.com/app. Если веб-версия работает, временно используйте её
- Если браузер тоже не подключается, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- Дополнительное обсуждение: [#252](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/peltcashierrepresent/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не запускаются игры или нет подключения

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`
- если этого недостаточно, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Лучше выяснить IP-адреса, которые использует игра, и добавить их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/peltcashierrepresent/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Создайте обращение [здесь](https://github.com/peltcashierrepresent/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Новые адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, это полезно, когда IP-сеть указана в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
